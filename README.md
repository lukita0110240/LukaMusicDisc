# LukaMusicDisc

Mod para Minecraft Java 26.1.2 con Forge.

## Compilación

El proyecto incluye un flujo de GitHub Actions en `.github/workflows/build.yml`.
Se ejecuta automáticamente al subir cambios a `main` o manualmente desde la pestaña **Actions**.

Cuando la compilación termina correctamente, el archivo JAR queda disponible en los artefactos de esa ejecución con el nombre `LukaMusicDisc-Minecraft-26.1.2-Forge`.

## Contenido

Añade el disco personalizado **Titanes** para reproducir el audio `titanes.ogg` en una jukebox.
